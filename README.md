🍿 usePopcorn

A React movie search and watchlist app. Search for movies, view details and ratings, and build your own personal watched list — complete with your own ratings and stats.

Built while learning React hooks, custom hooks, and component composition.

✨ Features
🔍 Search movies by title using the OMDb API
🎬 View movie details — poster, plot, cast, director, IMDb rating, runtime, and genre
⭐ Rate movies you've watched with an interactive star rating component
📋 Watched list — track movies you've seen, with your personal rating
📊 Stats summary — average IMDb rating, average user rating, and average runtime across your watched list
❌ Remove movies from your watched list
⌨️ Keyboard shortcuts — press Enter to focus the search bar, Escape to close movie details
💾 Persisted state — your watched list is saved to local storage between sessions

🛠️ Built With
React (CRA)
Custom Hooks — useMovies, useLocalStorageState, useKey
OMDb API for movie data
CSS (no framework)
